## 📌 Project Overview

**Smart Food Corner** is an interactive food ordering and restaurant management application built using **Python, Object-Oriented Programming (OOP), and Streamlit**.

The application simulates a restaurant ordering workflow, bringing together customers, menu items, billing, and delivery partner management through an interactive web interface.

The goal of this project is to apply Python programming concepts to a practical use case while developing an understanding of object-oriented design and interactive application development.

## ✨ Key Features

- 🍽️ **Restaurant Menu:** Browse food items, prices, and categories.
- 👤 **Customer Management:** Represent customers and their interactions with the ordering system.
- 🛒 **Food Ordering:** Place food orders through the application.
- 🧾 **Automated Billing:** Calculate order totals with applicable GST and packaging charges.
- 💳 **Wallet Functionality:** Support customer wallet operations, if enabled in the current application.
- 🛵 **Delivery Partner Management:** Represent delivery partners and manage the available delivery workflow.
- 🖥️ **Interactive Interface:** Navigate the application through Streamlit components.

## 🧠 OOP Concepts Applied

- **Classes and Objects:** Model customers, restaurants, menu items, and delivery partners.
- **Constructors:** Initialise objects with their required attributes.
- **Encapsulation:** Organise data and related functionality within classes.
- **Methods:** Define the behaviour of application entities.
- **Object Interaction:** Connect different components of the ordering workflow.

## 🔄 Application Workflow

1. Explore the restaurant menu.
2. Select food items and place an order.
3. Generate the bill with applicable charges.
4. Process the order through the available order-management workflow.
5. Manage delivery through the delivery partner functionality.

## 🚀 Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/shwetavanarse/Food-Delivery.git
cd Food-Delivery
```

**2. Create and activate a virtual environment**

```bash
python -m venv venv
venv\Scripts\activate
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
streamlit run streamlit_app.py
```

Open the local URL displayed in your terminal.
